# Claim Atlas demo

A working prototype of negotiation readiness for bodily-injury claims, as one page.

Open it: https://amsrau.github.io/claim-atlas-demo/

Everything shown is synthetic. No real person, provider, law firm or claim appears. The tool
never values a claim, scores credibility, sets a reserve or recommends an offer.

Anything you confirm, dispute or file is kept only in your own browser.
